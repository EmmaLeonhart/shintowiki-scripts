# Paused label output — not in the drip

Files here are **generated label proposals that are deliberately NOT being submitted**. They sit
outside `shinto-label-generator/quickstatements/` for one mechanical reason:
`modern-quickstatements/select_label_proposals.py` builds the daily drip by
`QS_DIR.glob("*.txt")` over that directory and pools the raw lines, ignoring filenames. Anything in
there goes out. Moving a file here is the way to stop it without deleting the work.

## `religious_building_en.txt` — paused 2026-09-17

22,548 English labels for churches, cathedrals, chapels, mosques and synagogues, generated by
`generate_religious_building_labels.py` and live in the drip until today.

**Why it stopped.** Emma, 2026-09-17: *"This is a complex task involving possibly 50 separate
decisions and imposing ontology on all religious buildings. Earlier sessions underestimated the
difficulty and used wikimedia commons as the only source like it was somehow authoritative."*

The generator takes the item's Commons category (P373), checks it is Latin script, and uses it
verbatim as the English label. Measured over all 22,548 lines, that premise does not hold:

| | |
|---|---|
| labels with **no English type word at all** | **15,001 (67%)** |
| Church | 5,147 |
| Chapel | 1,652 |
| Synagogue | 389 |
| Monastery | 167 |
| Mosque | 154 |
| Cathedral / Temple / Basilica / Abbey | 38 |

A Latin-script Commons category is frequently not English — `Kirche Rehden`, `St.-Petri-Kirche`,
`Jerusalemkirche`, `San Giovanni Battista`, `Madonna del Pero` — so these are German and Italian
strings being written into `en` labels. The script-check only ever asked whether the characters were
Latin, never whether the string was English.

⚠ **Some of these already reached Wikidata**, because the file was in the drip pool from whenever it
was first generated until 2026-09-17. Nothing here reverts those; pausing only stops more going out.

**It is also unwired from CI** — the `label-generator-regenerate.yml` step that would refresh it was
removed in the same commit. The generator still exists and still runs by hand.

**To resume:** move the file back into `shinto-label-generator/quickstatements/`. Nothing else is
needed, which is exactly why `tests/test_paused_labels_stay_out_of_the_drip.py` pins it.
