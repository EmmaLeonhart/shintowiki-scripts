# BFS layer analysis — what each layer is, and how to label it

Forward-only crawl from the 54 shrine-ranking seed concepts. Types are Wikidata
`P31`. **Already-covered = excluded from new labelling work** (but NOT pruned from
the graph — they still get traversed): Shinto shrines (`P31/P279* Q845945`,
algorithmic names), Buddhist temples (`Q5393308`), and the Shikinaisha list
articles (the `generate_shikinaisha_list` pipeline). Generated by
`analyze_layers.py` → `layer_analysis.json`.

## Per-layer summary

| Layer | Total | Shrine (covered) | Temple | Shikinaisha list | **To-do** |

The shrine share climbs fast (0 → 12% → 63%) and everything else is increasingly
**off-domain drift** (see below). The labelling-worthy *new* content is
concentrated in layers 0–2 and thins from there.

## Layer 0 (54) — the ranking ontology itself

Almost entirely `shrine rank` (Q10444029 ×47): Kanpei Taisha, Kokuhei Shōsha,
Ichinomiya, Myōjin Taisha, … plus a few `Wikimedia category`, `hierarchy`, the
Gifu ranking system, and Engishiki Jinmyōchō as `religious text`/`literary work`.

**Labelling approach — NEW.** These are Shinto technical terms with fixed
Japanese names (官幣大社, 一宮…). Same shape as the Shikinaisha job: transliterate
the romaji term into each script (reuse the existing machinery), Latin keeps the
romaji. No "Shrine"-style affix — the term *is* the label. Small, fixed set (~50)
→ a hand-curated seed table is realistic and higher-quality than pure
transliteration.

## Layer 1 (183) — lists + categories + text/metadata

`Shikinaisha list` ×70 (**already done**), `shrine` ×22 (**covered**). The 91
to-do are mostly **Wikimedia infrastructure** (`category` ×36, Wikipedia language
editions ×5, WikiProjects) and **text/language metadata** (`written work`,
`kanazukai`, `database`, a `prefecture`, `historical country`, Shinto-as-religion).

**Labelling approach:** mostly **skip** — categories, wiki editions, and languages
already have labels everywhere and aren't Shinto content. The genuine targets here
are the few **texts/concepts** (kanazukai, the Engishiki DB, Shinto itself) →
transliterate/gloss, same as layer 0.

## Layer 2 (4 932) — shrines + heavy geographic drift

63% **shrines (covered)**. The 1 802 to-do split into three clear buckets:

**(B) Shinto-domain, worth labelling:**
- `kami` (Q524158 ×17 and climbing) — deities. → **NEW generator**: transliterate
  the deity name exactly like shrine names (romaji → scripts); the existing
  transliterators apply directly.
- `province of Japan` (Q860290 ×68), historical provinces — the same province
  names the Shikinaisha frame already transliterates. → reuse that; can emit
  standalone province labels.

**(C) Japanese geography — low priority:** `prefecture of Japan` ×49, `city of
Japan` ×30. Real places shrines sit in; most already carry community labels in
major languages. → transliterate into missing scripts only if we want full
coverage; not urgent.

**(D) Off-domain drift — skip:** `country` ×126, `sovereign state` ×121,
`bilateral relation` ×76, `modern/natural language`+`dialect` ×100+, `human` ×29,
`encyclopedia article` ×42, `international organization`, `WikiProject` ×17. These
come in via forward links (shrine → country → bilateral relations → other
countries; text → language → editions). All already globally labelled and not
Shinto. Their bulk at layer 2 is the **signal that layers 3–5 will be mostly
drift.**

## Labelling approaches, consolidated

| Bucket | Example types | Approach |
|---|---|---|
| Shrines | `Q845945`* | **Covered** — algorithmic names |
| Buddhist temples | `Q5393308` | **Covered** — algorithmic names |
| Shikinaisha lists | list articles | **Covered** — `generate_shikinaisha_list` |
| **Shrine ranks** | `Q10444029` | **NEW** — transliterate the JP term (curated seed table, ~50) |
| **Kami / deities** | `Q524158` | **NEW** — transliterate deity name (reuse shrine transliterators) |
| **Provinces** | `Q860290` | reuse the Shikinaisha province transliteration |
| Shinto texts/concepts | religious text, kanazukai | transliterate/gloss (small) |
| JP geography | prefecture, city | transliterate into missing scripts; low priority |
| Drift (countries, langs, humans, orgs) | `Q6256`, `Q34770`, `Q5`… | **skip** — already labelled, not Shinto |
| Wikimedia infra | category, disambig, WikiProject | **skip** |

**Bottom line:** beyond what's already covered, the two clearly worthwhile new
label generators are **shrine ranks** and **kami/deities** — both are just
term/name transliteration with the machinery that already exists. Provinces are a
cheap reuse. Everything else is either already-labelled geography or forward-link
drift that grows to dominate the deeper layers.
