ARTICLE TITLE: 櫛田神社 (福岡市)

櫛田神社（くしだじんじゃ）は福岡県福岡市博多区上川端町にある神社。旧社格は県社。博多の旧市街（博多部）に位置しており、地元の博多の人々からは「お櫛田さん」と愛称で呼ばれる。正式名称は、博多総鎮守櫛田神社（はかたそうちんじゅくしだじんじゃ）。


== 概要 ==
博多の氏神・総鎮守として古くから信仰されている神社。7月の博多祇園山笠や10月の博多おくんちなど祭事が行われる。5月の博多松囃子（博多どんたく）は厳密には櫛田神社の祭事ではないものの、松囃子一行は櫛田神社から出発するしきたりになっている。
800年近い歴史を持つ博多祇園山笠は、博多の総鎮守・櫛田神社の奉納行事で、2016年にユネスコ無形文化遺産に登録された福岡を代表する祭りである。


== 祭神 ==
祭神は大幡主大神（櫛田大神）、天照皇大神、素盞嗚大神（祇園大神）の三神で、正殿に大幡主大神、左殿に天照皇大神、右殿に素盞嗚大神が祀られている。大若子命は、越国（現在の北陸地方）で反乱を起こした阿彦の征討に行くよう命を受け、その平定の報告をした際にその功績を認めた朝廷から「大幡主」の名を与えられている。
以前は3つの社にそれぞれ祀られていた。大幡主は孝謙天皇天平宝字元年（757年）託宣によって鎮座。素戔嗚大神は天慶4年（941年）藤原純友の乱の追討使小野好古が戦勝奉賽のために勧請された。天照大御神については明確な記録が残っていないという。
元々は櫛名田姫を祀る神社であったとする説もあるが、日本全国にある7つの櫛田神社のうち櫛名田姫を主祭神とする神社は2つのみ。1社は三重県桑名市にあり、創建年も沿革も不明。もう1社は武内宿禰が創建したとされる富山県射水市の櫛田神社 (射水市)である。
当社は三重県松阪市にある櫛田神社 (松阪市)、京都府京都市の松阪神社より勧請されており、櫛名田姫はいずれにも祀られていない。
なお、大幡主大神（大若子命）を主祭神とする神社5社のうち3社は北陸地方にあり、残る2社は同じ福岡市内の野芥櫛田神社と、野芥櫛田神社から分霊した荒江櫛田神社である。
平忠盛により博多に新しく櫛田神社が造られた際に、櫛名田姫を祀る佐賀県神埼市の櫛田宮を勧請したものが、現在の博多の櫛田神社の元であるとする説もある。しかし、博多の櫛田神社創建の757年に対して平忠盛が生誕したのは1096年であり、元々櫛名田姫が祀られていた博多の櫛田神社の元宮が神埼の櫛田宮であるとする説の根拠は不明である。


== 歴史 ==
社伝では、天平宝字元年（757年）、松阪にあった櫛田神社を勧請したのに始まるとされ、松坂の櫛田神社の祭神の大幡主大神が天照大神に仕える一族の神であったことから、天照皇大神も一緒に勧請されたと伝えられる。天慶4年（941年）、小野好古が藤原純友の乱を鎮めるために京都の八坂神社に祈願し、平定した後に当社に素盞嗚神を勧請したと伝えられる。
平安時代末期、平忠盛が所領の肥前国 神埼（佐賀県神埼市）の櫛田宮から、博多での船舶による交易のために作られた神崎庄倉敷に、同名となる櫛田神社を創建して勧請したことを根拠に佐賀県神埼市の櫛田宮が元宮であるという説があるが、櫛田神社の創建年（757年）と平忠盛の生存年（1057年生誕）を考慮すると、誤解があったようである。しかしながら、櫛田神社の宮司らが編纂し1965年（昭和40年）に文部省（当時）に提出した『博多山笠記録』や1979年（昭和54年）に福岡市が発行した『福岡の歴史』では、佐賀県神埼市にある櫛田宮の分社との説があると記載されている。
戦国時代に荒廃したが、1587年（天正15年）、豊臣秀吉によって博多が復興されるときに現在の社殿が造営された。
1868年（明治元年）の神仏分離令より前の江戸時代までは東長寺に属する神護寺が櫛田神社を管理していた。
1891年（明治24年）に県社に列した。


== その他 ==
福岡県福岡市博多区の祇園町の名前は同神社に祀られている祇園大神に由来するといわれている。
博多祇園山笠の飾り山が常設されている。1960年（昭和35年）から『走れ!山笠』を放送し続けている九州朝日放送（KBC）が奉納している。
また、境内の入り口付近には「櫛田の銀杏(ぎなん)」と呼ばれる樹齢約1000年の銀杏の木がそびえる。「博多祝い唄」にも謡われ、県の天然記念物に指定されている。
山笠に牡丹が飾られる由来となった松浦党の波多三河守親ゆかりの切木のボタンが、2018年（平成30年）11月に唐津市肥前町から株分けされ、境内に植樹された。
1955年（昭和30年）の台風22号では、境内のエノキが倒れるなどの被害が出た。
